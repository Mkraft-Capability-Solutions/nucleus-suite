# Domain service design

Each row defines a service boundary and its acceptance focus. These are target designs; the feature catalog ties every current menu, operational form, action dialog, widget and route to this design. Existing service files are compatibility entrypoints, not evidence that all listed behavior works end to end.

| Domain / service ownership | Explicit records and queries | Commands and state rules | Acceptance and dependencies |
| --- | --- | --- | --- |
| Identity, platform access, admin, platform-admin | Users, sessions, memberships, roles, permission grants, scopes, support elevations | Invite, accept, revoke, change grants, enable tenant; prevent self-escalation and last-admin lockout | Session expiration, CSRF, role revocation mid-session, cross-tenant denial, elevated support expiry; prerequisite for all domains |
| Organization | People, employments, assignments, org units, positions, sanctioned slots, reporting edges | Create person/employment; assign/transfer/end assignment; approve headcount; reject reporting cycles and overlapping primary assignments | Effective-dated hierarchy and manager scopes, uniqueness and concurrent slot filling; emits employment/assignment changes |
| Attendance | Punch events, shifts, rosters, daily calculations, exceptions, gate passes, overtime requests | Ingest idempotent punches; pair intervals; recompute versioned day; resolve exception; approve overtime | Overnight/DST shifts, missing punches, duplicate devices, cutoff and recompute trace; consumes employment/rosters and publishes payroll-ready summaries |
| Leave | Types, policy versions, eligibility, requests, approval steps, credits/debits/reservations | Apply, submit, approve, reject, cancel, accrue, expire, reconcile early return | See SCR-030 contract; immutable ledger, overlap/balance concurrency, no duplicate deduction; consumes attendance calendars and feeds payroll |
| Lifecycle | Joiners, onboarding templates/tasks, probation decisions, exit cases, clearances, asset handovers, letters | Start joining chain; complete evidence-based task; confirm probation; initiate/approve exit; collect assets; issue versioned letter | Required-document and task dependencies, assignment access dates, reopening versus immutable evidence; exit feeds final settlement |
| Talent and interviews | Requisitions, candidate consent, applications, stages, interviews, scorecards, offers, referrals | Approve requisition; progress/reject candidate; schedule/reschedule interview; score independently; approve offer; convert hire | Capacity limits, duplicate candidates, stage constraints, panel conflicts and private feedback; conversion links candidate to person once |
| Performance | Cycles, participants, goals, weighted objectives, reviews, feedback, calibration, succession nominations | Open cycle, submit goals/reviews, request feedback, calibrate, finalize | Weight sums, reviewer access, confidential feedback, cycle cutoffs and no editing finalized ratings; consumes reporting hierarchy |
| Learning and skills | Course catalog, paths, enrollments, completions, skill taxonomy, evidence, proficiency assessments | Enroll/withdraw; validate prerequisite; approve completion; assess skill; expire credentials | Duplicate enrollment, prerequisite cycles, revoked proof, role-appropriate access; learning events update skills via application port |
| Engagement | Recognition, awards, wellbeing cases, surveys and responses | Nominate/approve recognition; assign follow-up; submit protected response | Award budget, self-approval, anonymity threshold and restricted wellbeing records; no fabricated sentiment or employee surveillance |
| Compensation | Salary structures, components, grade bands, compensation cycles, proposals | Simulate, submit change, approve, effective-date profile | Currency consistency, band validation, effective-date overlap, weighted budgets, simulation never mutates salary; publishes approved payroll profiles |
| Payroll | Profiles, component lines, runs, input snapshots, result lines, approval records, payslip versions | Open run, freeze inputs, calculate job, review, approve, lock, amend through linked correction | Exact money, deterministic replay, concurrent finalization, negative net-pay policy, separation of preparer/approver; consumes attendance/leave/compensation |
| Advances and loans | Eligibility decisions, advance requests, loan contracts, guarantors, schedules, repayments | Request EWA/advance/loan; reserve guarantor capacity; approve; disburse instruction; deduct/reconcile | Available-earned balance, integer tenure, guarantor consent/locks, independent approval, duplicate disbursement; feeds payroll deductions |
| Benefits | Plans, eligibility, enrollments, dependents, coverage periods | Enroll/change/terminate coverage, publish enrollment window | Effective dates, annual limits, duplicate coverage, privacy of dependents; consumes employment and emits payroll benefit inputs |
| Compliance | Jurisdictions, rule packs, registrations, obligations, filings, accident cases, evidence | Review/publish policy pack, schedule obligation, approve filing, acknowledge submission, record accident | India/state setup and golden cases required; immutable submitted evidence; legal review is an explicit release gate |
| Finance, FX and exports | Currency rates, GL mappings, journal lines, disbursement batches, bank acknowledgments, reconciliations | Version rates/mappings; generate approved journal/bank export; import response; reconcile | Balanced journal, distinct employee beneficiaries, totals matching locked run, FX provenance, no bank execution from previews |
| Contractors | Vendors, contracts, workers, deployments, attendance submissions, invoice lines, reconciliation findings | Onboard vendor/worker; assign contract; submit attendance; review/reconcile invoice | Contract effective dates, worker duplication, attendance totals, tax/policy applicability review and tenant-scoped vendor access |
| Operations | Projects, tasks, time entries, rosters, travel/expense requests, service tickets | Create/assign/transition task; log/approve time; submit/approve expense; route/resolve ticket | Time intervals and bounded hours, duplicate expenses/evidence, cost derivation, SLA clock pause rules; domain-specific child tables rather than generic attributes |
| Documents and privacy | Document versions, attachments, scan jobs, access grants, retention rules, holds, subject requests | Upload/quarantine/scan/release; acknowledge policy; export/erase subject data under review | Malware/quota checks, signed-download expiry, retention holds, field minimization, access revocation; no sensitive files in public storage |
| Delegation and workflow governance | Workflow definitions/versions, instances, steps, decisions, delegate grants | Validate/publish workflow; start instance; decide step; delegate/revoke; escalate | Graph cycles, unreachable terminal states, missing approvers, maker-checker rules, exactly-once side effects and version-pinned instances |
| Integrations | Connector configurations, secret references, mappings, inbound events, sync checkpoints | Configure/test/enable; ingest signed webhook; run sync; retry failed item | Signature/replay checks, secret masking, idempotency, partial failure, mapping validation and provider outage; no tenant-controlled arbitrary network targets |
| Notifications | Templates/versions, preferences, delivery intents, attempts, receipts | Publish template; enqueue; deliver/retry; mark read; unsubscribe optional communications | Deduplication, localization, mandatory-versus-optional policy, provider rate limits; outbox is the only business delivery trigger |
| Analytics | Metric definitions, projections, report definitions, schedules, exports | Publish metric/report definition; rebuild projection; schedule/export | Filter scope, lineage, freshness, exact denominators, privacy thresholds, no inference from partial pages; read projections rather than blocking payroll writes |
| AI and VP | Knowledge sources, retrieval grants, model runs, proposed actions, approvals, executions, evaluations | Retrieve scoped context; propose action; approve; execute through existing domain command; reverse where supported | Prompt-injection boundaries, PII minimization, budget/time limits, no authority from generated text, no direct model SQL or payment execution |
| Dashboard | Widget definitions, user-console layouts, revisions, authorized query projections | Save/reset/import layout, move/resize widget, query authorized data | Role/grant filtering at server, keyboard/touch parity, layout conflicts and stale-permission pruning; presentation edits never change business records |
| Public website and content | Published pages, navigation, documentation versions, contact inquiries, consent | Publish content; submit/rate-limit contact inquiry; triage without exposing tenant data | Shared public/login header, themes, mobile navigation, accessible forms, real delivery status; public content isolated from HR fixtures |
| Localization and global configuration | Messages, translations, locales, typed definitions, global and tenant values | Draft/validate/publish/rollback; configure country capabilities | Missing-key fallback, plural variables, cache revisions, scope overrides, no secrets or employee data in public bundles |

## Cross-domain workflows

1. Hire: sanctioned position → approved requisition → selected candidate → approved offer → idempotent person/employment creation → joining tasks → assignment and payroll profile eligibility. Failed downstream tasks stay resumable; they do not duplicate the employee.
2. Monthly payroll: approved time/leave cutoff → profile and policy snapshot → deterministic calculation job → audit exceptions resolved → independent approval → locked run → payslips, journal and disbursement instruction → bank response reconciliation. Failed delivery does not unlock or recalculate an approved run.
3. Exit: approved last working date → revoke future access per policy → clearance/asset evidence → final settlement inputs → approved correction-aware payout → retention schedule. Employment history survives access revocation.
4. Country activation: global draft catalog → reviewed rule pack and fixtures → capability validation → Superadmin publish → tenant establishment setup → effective employee assignments. Historical calculations retain prior country/rule versions.
5. Delegated approval: verify delegate grant at decision time → record both identities → version-check pending step → apply one domain transition → outbox notification. Expired or cross-scope delegation is rejected.

## Domain-specific UI requirements

Every service-integrated screen needs loading, empty, filtered-empty, permission-denied, unavailable, partial-results and stale-data states. Pending commands disable only affected controls and preserve the user's input. Save confirmation must reflect persisted state. Mobile prioritizes self-service requests, time actions, approvals, payslips and notifications; bulk configuration and large reconciliations may offer a read-only summary plus an explicit desktop task handoff. Do not hide the only route to an essential employee function.
