# Interface localization and design tokens

`src/context/I18nContext.tsx` provides locale-aware `useTranslation`; `src/lib/i18n.ts` resolves messages, interpolates named values and falls back to the published English catalog. React renders results as text. Never pass translated content to dangerouslySetInnerHTML.

`src/services/localization.ts` is the asynchronous published-catalog boundary. It currently publishes English only; unsupported locale requests resolve to English rather than claiming a translation exists. Replace this adapter with the reviewed localization repository at database cutover. Public page copy is indexed from public-site.json without duplicating its English source, and the public-content adapter resolves those message paths. Route, icon and record identifiers are excluded from translation.

New interface strings belong in `src/data/locales/en/interface.json` with meaningful namespace/key names. Existing extracted keys are stable hashes scoped to their source components. Use named interpolation values instead of sentence concatenation. Client components use the hook; server components use the resolver or localized content adapter. Avoid a local variable named `t` shadowing a translator; extracted components use `translateText`.

Run `node scripts/verify-interface-copy.mjs` to check that literal translation references resolve and that the direct JSX text/label scan has no findings. The scan covers JSX text and common label attributes, not every possible programmatically constructed message or business record. Existing workspace fixtures remain behind readData; their database-driven localization and business-data migration are separate open work.

Colors belong in the appearance catalog or named semantic CSS tokens. Shared layout dimensions and radii belong in root design tokens. Structural CSS rules, responsive breakpoints, code identifiers, units and validation invariants are not translation strings. Do not blindly translate those values or replace business records with message text to satisfy a superficial zero-literal count.
